# AI Partner Method — Direct Response Copywriting Toolkit

> Built and shipped by **Brett Zuke** for students inside the **AI Partner Method**.

The complete direct-response copy system: frameworks, voice rules, psychological triggers, 85 headline templates, and ready-to-edit scripts for VSLs, sales pages, and paid ads. Designed to plug into [Claude Code](https://claude.com/claude-code) so you can write a 3,000-word VSL or a long-form sales page from a one-page brief.

This is the same system powering live client copy inside the AI Partner Method. Open the repo, fill in the brief, ask Claude — get a draft in minutes that would otherwise take days.

## Quickstart (90 seconds with Claude Code)

```bash
git clone https://github.com/BrettZuke/ai-partner-method-direct-response-toolkit.git
cd ai-partner-method-direct-response-toolkit
cp examples/brief.example.json my-brief.json
# edit my-brief.json with your client info
claude
```

Then in your Claude session:

> *"Write me a VSL script using `my-brief.json`."*
>
> *"Write a long-form sales page for the same brief."*
>
> *"Give me 10 headline variants for this offer using the swipe file."*

Claude reads the brief, follows the SOP, picks the right framework based on your audience awareness level, and produces a draft ready to edit.

## Why this exists

Most copywriting "training" hands you a 50-hour video and a PDF of swipe files. You finish, sit at the blank page, and freeze.

This toolkit is the opposite: a tight system with **frameworks**, **rules**, and **starting points** you adapt — plus an AI that knows how to use them. The skill you're building isn't typing or remembering Eugene Schwartz quotes — it's writing good briefs and editing for voice.

If you're brand new to copy: read [ONBOARDING.md](ONBOARDING.md), then write one piece using one framework. Don't try to learn everything at once.
